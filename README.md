## About

Trust Me Secure builds **PassKub**, an offline-first password and secret
manager available on Android, iOS, Windows, macOS, and Chrome/Edge — with
optional end-to-end encrypted cloud sync for teams and families.

Every product we ship follows the same principle: your secrets are yours.
Master passwords never leave your device, encryption keys are never stored
on our servers, and the server only ever sees ciphertext.

## Security

- **Argon2id** key derivation + **AES-256-GCM** authenticated encryption
- Zero-knowledge architecture — the server never sees plaintext or keys
- Found a vulnerability? Report it to **service@passkub.com**
